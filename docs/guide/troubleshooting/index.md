# Troubleshooting

Use this section when something goes wrong starting servers, or talking to Protocube or the daemon. Each page focuses on one class of problem; expand them with real log lines and version-specific notes as you document them.

## Common issues

| Topic | When to open it |
| --- | --- |
| [Docker issues](./docker-issues) | Docker networking errors, container runtime setup issues, or network pool/subnet conflicts |
| [Server connection issues](./server-connection-issues) | Can’t connect to a game server (timeouts, wrong host/port, Docker vs host, or external access) |
| [API or connectivity](./api-or-connectivity) | Can’t reach Protocube, auth, or timeouts from clients |

If you are stuck, ask in the [Discord](https://discord.gg/BrH8GtyGSh) and include versions, relevant config (redacted), and log snippets.
